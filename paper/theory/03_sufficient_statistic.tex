\section{What a memory must keep}\label{sec:statistic}

\begin{definition}[Authority state]
The \emph{authority state} of a history is
$\sigma(h) = \big( (\st_k(h))_{k \in \Keys},\ (\Out_a(h))_{a \in \Act} \big)$: for each key, the
value the customer and the books determine (or $\bot$, or $\conflict$), and for each action, its
outstanding requests with the objects and arguments they name.
\end{definition}

\begin{theorem}[Sufficiency and necessity]\label{thm:statistic}
\begin{enumerate}
\item[(i)] $\Perm(h, \cdot)$ is a function of $\sigma(h)$.
\item[(ii)] No component can be dropped. For each of the following, there are histories $h, h'$
  that differ only in it, with $\Perm(h, o) \neq \Perm(h', o)$ for some $o$, possibly after a
  common continuation: the value state of a key ($v$ against $\bot$, against $\conflict$, or
  against another value $v'$); the presence of an outstanding request; the object a request
  names; an argument a request names; whether a request has been spent.
\item[(iii)] A representation $\mu$ admits a rule that is sound and executes every permitted
  operation without asking, on $\mathcal{H}$ and all its continuations, if and only if $\mu(h)$
  determines $\Perm(hu, \cdot)$ for every continuation $u$. This holds in particular when
  $\sigma$ factors through $\mu$.
\end{enumerate}
\end{theorem}
\begin{proof}
(i) Definition~\ref{def:perm} reads nothing else.

(ii) The witnesses are Examples~\ref{ex:source}--\ref{ex:correction}. For the three key states:
if $\st_k(h) = v$ and $\st_k(h') \in \{\bot, \conflict, v'\}$, append an own-voice request that
names everything but the parameter on $k$; then binding $v$ is permitted after $h$ only. If
$\st_k(h) = \bot$ and $\st_k(h') = \conflict$, first append an own-voice assertion of a fresh value
$w$ under $k$; after $h$ the state becomes $w$, after $h'$ it stays $\conflict$.

(iii) By Theorem~\ref{thm:indist} applied to every continuation.
\end{proof}

\begin{proposition}[One bit of label is enough to act]\label{prop:onebit}
Without a customer, the decisions of $G$ depend on labels only through $[\ell(r) = \Au]$.
\end{proposition}
\begin{proof}
Steps~1--2 test ``$\Au$'' and nothing finer; any other outcome refuses.
\end{proof}

The three-level label carries one decision bit. The difference between $\At$ and $\Un$ matters
only to the customer, who is shown the least trusted source of a value.

\begin{remark}[The gate against the optimum]
Under faithfulness and completeness the store determines $\sigma$, so $D^*$ is computable from it.
$G$ equals $D^*$ with one deliberate exception. When the customer's value under $k$ is unique but
another source gives a different value, $\st_k = v$ and $D^*$ binds $v$, whereas $G$ sees two
values on record and does not execute without the customer. The gap costs TSR and never ASR.
The same holds for requests naming two objects. The agent's proposals close exactly this gap: if the
agent proposes $v$, $G$ binds it, because an $\Au$ record carries it. The cost is that $G$ then
implements selection rather than uniqueness (Section~\ref{sec:selection}).
\end{remark}

\subsection*{The exact minimal memory}

Theorem~\ref{thm:statistic} says what cannot be dropped. It does not say exactly when two
histories are interchangeable for every future. That needs the future made precise.

\begin{definition}[Admissible continuations]
A continuation is a sequence of own-voice customer messages, messages on other channels, and
executions of operations that are permitted at the point where they occur. A sound system
executes nothing else. Interface approvals are left out here; they are the subject of
Section~\ref{sec:queries}. Histories $h, h'$ are \emph{equivalent}, $h \equiv h'$, if
$\Perm(hu, o) = \Perm(h'u, o)$ for every admissible continuation $u$ and every $o$. This is the
Nerode equivalence of $\Perm$.
\end{definition}

\begin{definition}[Request state]
For an action $a$, collapse $\Out_a(h)$ to $\rho_a(h)$:
\begin{itemize}
\item $\mathsf{absent}$ if $\Out_a(h) = \emptyset$;
\item $\mathsf{blocked}$ if the requests name two different objects, or two different values
  for some parameter;
\item otherwise $(n_o, (c_p)_{p \neq s_a})$, where $n_o$ is the one object named or $\bot$, and
  $c_p$ is the one value named for $p$ or $\emptyset$.
\end{itemize}
A request state is \emph{bare} if it is $(\bot, (\emptyset)_p)$: something was asked for and
nothing was named. The \emph{canonical state} is $\tilde\sigma(h) = ((\st_k(h))_k, (\rho_a(h))_a)$.
\end{definition}

\begin{lemma}[The canonical state is a state machine]\label{lem:machine}
$\Perm(h, \cdot)$ is a function of $\tilde\sigma(h)$, and $\tilde\sigma(he)$ is a function of
$\tilde\sigma(h)$ and the event $e$:
\begin{itemize}
\item an assertion of $v$ under $k$ turns $\bot$ into $v$ and a different value into $\conflict$;
\item a request merges into $\rho_a$, and any disagreement gives $\mathsf{blocked}$;
\item a permitted execution of $a$ resets $\rho_a$ to $\mathsf{absent}$.
\end{itemize}
Both $\conflict$ and $\mathsf{blocked}$ are absorbing.
\end{lemma}
\begin{proof}
$\Perm(h, (a, \theta)) = 1$ iff $\rho_a$ is neither $\mathsf{absent}$ nor $\mathsf{blocked}$,
$\theta(s_a)$ equals $n_o$ (or, if $n_o = \bot$, equals $\st_{\kappa_a(s_a)}(h) \in \V$), and every
other $\theta(p)$ equals $c_p$ (or, if $c_p = \emptyset$, equals $\st_{\kappa_a(p)}(h) \in \V$). A
permitted execution has $\theta(s_a)$ equal to the only object in play. So it spends every
outstanding request (Definition~\ref{def:standing}). A blocked action is never permitted, so it
is never reset.
\end{proof}

\begin{theorem}[When two histories are interchangeable: static regime]\label{thm:exact}
Let $\V$ be infinite and every key be read by some parameter. Reduce the canonical state in two
ways:
\begin{enumerate}
\item[(a)] erase $\st_k$ for every key all of whose reading actions are $\mathsf{blocked}$;
\item[(b)] replace a bare $\rho_a$ by $\mathsf{absent}$ when some key read by $a$ is $\conflict$.
\end{enumerate}
Then $h \equiv h'$ if and only if their reduced canonical states are equal.
\end{theorem}
\begin{proof}[Proof]
\emph{If.} By Lemma~\ref{lem:machine}, it suffices that the reductions commute with every event
and do not change $\Perm$. (a): a blocked action never becomes unblocked, so an erased key is
never read again. (b): a bare request adds nothing to any merge, so bare $\oplus\, r = r =
\mathsf{absent} \oplus r$. Before a new request arrives, the action reads a key stuck at
$\conflict$ and is never permitted, exactly as when $\mathsf{absent}$.

\emph{Only if.} Each difference between reduced states is separated by an admissible
continuation. Values named in these continuations are fresh unless stated otherwise.
\begin{itemize}
\item \emph{$\rho_a$ differs.} Against $\mathsf{blocked}$: a request naming everything
  consistently with the other side permits it, and $\mathsf{blocked}$ stays refused. A named
  value $u$ or object $o$ on one side only: a request naming a fresh value there blocks that
  side and not the other. $u$ against $u'$: a request repeating $u$ permits one side and blocks
  the other. Bare (not reduced) against $\mathsf{absent}$: no key of $a$ is $\conflict$, so
  asserting fresh values for the keys at $\bot$ permits the bare side only.
\item \emph{$\st_k$ differs, with the $\rho$'s equal.} Pick an unblocked reader $a$ and a
  parameter $p$ with $\kappa_a(p) = k$. If $\rho_a$ names $p$, then $k$ holds $u$ or $\conflict$
  on both sides. First name every parameter consistently and execute on both sides, which is
  permitted and equal. Then request $a$ naming everything but $p$. The permission now reads
  $\st_k$ alone, and the two sides differ.
\end{itemize}
\end{proof}

\begin{corollary}[Size of the minimal memory]\label{cor:size}
With $N$ possible values, the classes number at most
$\prod_k (N + 2) \cdot \prod_a \big( (N + 1)^{|P_a|} + 2 \big)$. So a memory that decides every
future exactly needs about
$\sum_k \log_2 (N + 2) + \sum_a |P_a| \log_2 (N + 1)$ bits in the worst case. This covers the
customer's own values per key (or none, or contested) and what each outstanding request names.
\emph{Values from anybody else contribute nothing.}
\end{corollary}

\begin{corollary}[Keep foreign content only with its source]\label{cor:dichotomy}
A memory can decide authority exactly without storing anything that did not come from the
customer or the books. A memory that does store foreign content, as an agent's memory does to be
useful, must also store what tells it apart from the customer's: at least one bit per value in the
worst case (Theorem~\ref{thm:bits}).
\end{corollary}

\subsection*{Revocation makes every state live}

\begin{theorem}[When two histories are interchangeable: revocable regime]\label{thm:exact-rev}
In the revocable regime (Definition~\ref{def:revocable}), let the canonical state be
$\hat\sigma(h) = ((\Vals_k(h))_k, (\rho_a(h))_a)$: the \emph{set} of live values per key, not its
collapse to $\bot$, $v$ or $\conflict$, and the request states as before. Let $\V$ be infinite and
every key be read by some parameter. Then $h \equiv h'$ if and only if
$\hat\sigma(h) = \hat\sigma(h')$. No reduction is needed.
\end{theorem}
\begin{proof}
\emph{If.} Lemma~\ref{lem:machine} carries over. A retraction removes a value from the set, an
expiry empties it, and a withdrawal resets $\rho_a$ to $\mathsf{absent}$. Permission reads the set
only through its collapse, and the updates are functions of the set.

\emph{Only if.} Take $v \in \Vals_k(h) \setminus \Vals_k(h')$. Retract every other value either side
holds under $k$; then $h$ holds $\{v\}$ and $h'$ holds $\emptyset$. Request a reader of $k$ naming
everything but that parameter, after withdrawing its earlier requests on both sides. Only $h$ is
permitted. Request states that differ are separated as in Theorem~\ref{thm:exact}, first
expiring and freshly re-asserting the keys the action reads so that nothing else blocks. The
static reductions disappear:
\begin{itemize}
\item a blocked action can be withdrawn, so its keys are read again;
\item a contested key can be resolved by retraction, so a bare request is no longer dead.
\end{itemize}
\end{proof}

\begin{corollary}[Revocation multiplies the memory]\label{cor:rev-size}
With $N$ values, the static regime needs $\log_2 (N + 2)$ bits per key. The revocable regime needs
$N$: every live value, contested ones included, must be remembered, because a later retraction
can resolve a conflict either way. A conflict can no longer be summarised as ``contested''. This
parallels ResidualAuth's redundancy--memory law for delegation (arXiv:2609.08062), where
revocation likewise raises the state from linear to quadratic in the exponent.
\end{corollary}

\paragraph{Reading.} What authority requires of a memory is small, and now exact: the customer's
own values per key, with ``none'' and ``contested'', and the named contents of outstanding
requests. It never requires foreign content. Section~\ref{sec:speech} and
Section~\ref{sec:consolidation} are where it stops being small. The voice cannot be computed from
the view, and a memory that compresses must lose information only in the few ways
Theorem~\ref{thm:safe} allows.
